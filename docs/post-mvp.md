# Post-MVP Notes - Non-Normative

This document is non-normative and does not authorize MVP scope, routes, infrastructure, requirements, tasks, or implementation.

For the MVP, use only the approved artifacts under `specs/001-leave-management-mvp/`, `specs/002-role-based-frontend-views/spec.md`, and `docs/use-cases.md`.

Current MVP exclusions include User Pending cancellation, additional leave types, partial days, holiday calendars, per-user timezones, public APIs, JWT, OpenAPI, email, Outbox, queues, Redis, microservices, teams, departments, managers, hierarchy, delegation, escalation, HR request resolution, HR balance modification, and HR role assignment/removal.

Any future capability requires a separate approved specification and, where required, an ADR or constitutional amendment before planning or implementation.
